JavaScript Smart Contracts on Bitcoin.

A Turing-complete metaprotocol for UTXO-based blockchains.

Run it in the playground Read the quickstart

Runs on Bitcoin, Litecoin, Dogecoin, Pepecoin. Bitcoin Cash soon.

index.html 
<html>
  <head>
    <script type="module">
      import { Computer, Contract }
        from 'https://unpkg.com/@bitcoin-computer/lib/dist/bc-lib.browser.min.mjs'

      // A smart contract
      class Counter extends Contract {
        constructor() { super({ n: 0 }) }
        inc() { this.n += 1 }
      }

      // Create and fund a wallet on testnet
      const computer = new Computer()
      await computer.faucet(1e5)

      // Create an on-chain object, then update it
      const counter = await computer.new(Counter)
      await counter.inc()
      const el = document.getElementById('count')
      el.innerHTML = counter.n
    </script>
  </head>
  <body>
    <span id="count">*</span>
  </body>
</html>

Save this as a file and open it in a browser. That is a smart contract running on testnet.

No Middlemen That Hold Your Coins

Most ways to run smart contracts on Bitcoin use a separate chain joined to Bitcoin by a bridge. Your coins typically move to an address that middlemen control. Bitcoin Computer runs directly on Bitcoin and Bitcoin-like chains. The coin that carries your object stays under your key, and its code and every call made to it are written into ordinary transactions. There is no bridge, no custodian, and nobody who can switch it off.

Fees Stay Flat No Matter How Much the Contract Computes

Only the people who use a contract run its code, not every validator on the network. The fee pays for the bytes a transaction takes up, not for the work inside it, so a call that runs a million steps costs the same as a call that runs one. On an account-model chain every validator would run all million steps and charge for each.

Your Data Is as Hard to Change as Your Coins

A smart object is carried by a coin, an unspent transaction output with a small amount in it. Updating the object means spending that output and creating a new one for the next version, which takes the owner's private key. So changing someone else's data is exactly as hard as stealing their Bitcoin, and miners enforce it.
